# Static policy divide

Set the amount of cluster nodes statically.

## Installation

Follow the [instructions](https://docs.halon.io/manual/comp_install.html#installation) in our manual to add our package repository and then run the below command.

### Ubuntu

```
apt-get install halon-extras-static-policydivide
```

### RHEL

```
yum install halon-extras-static-policydivide
```

### Azure Linux

```
tdnf install -y halon-extras-static-policydivide
```
